Privacy Policy — Cerveau Studio

Last updated: September 26, 2026

1. Data we access

When the account owner authorizes the App with TikTok Login Kit, the App receives:

  • basic account information (open ID, display name, avatar) — scope user.info.basic;
  • an access token allowing it to send videos as drafts to that account's TikTok inbox — scope video.upload.

2. How we use it

This data is used only to send the creator's own videos as drafts to their own TikTok inbox and to check the upload status. The creator publishes each draft manually in the TikTok app. The data is not used for advertising, profiling or any other purpose.

3. Storage

Access tokens are stored locally on the creator's own computer. No data is stored on external servers, and no personal data from other TikTok users is collected.

4. Sharing

We do not sell, rent or share any data with third parties.

5. Revoking access

The account owner can revoke the App's access at any time in TikTok (Settings > Security > Manage app permissions). Locally stored tokens can then be deleted.
